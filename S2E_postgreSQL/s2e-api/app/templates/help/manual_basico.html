Entrar
Esqueceu a senha?
  1. Abra o sistema no navegador. A tela de login será exibida automaticamente.
  2. No campo Usuário, digite o nome de usuário que foi criado para você.
  3. No campo Senha, digite sua senha.
  4. Clique no botão Entrar. Você será redirecionado ao Menu Principal.
Esqueceu a senha? Clique em "Esqueceu a senha?" na tela de login. Informe o e-mail cadastrado e você receberá um link para criar uma nova senha.

3
Registrar Saída
Buscar o aluno e registrar a saída do dia
  1. No Menu Principal, clique em Registrar Saída (ou use o link no menu lateral).
  2. Digite o nome ou o RA do aluno no campo de busca. Os alunos vêm do sistema de cadastro da escola.
  3. Clique no aluno correto na lista de resultados.
Formulário de Registro de Saída Ao clicar em Registrar Saída, preencha: Data, Horário, Motivo (ex: consulta médica) e Responsável da escola (funcionário que autorizou a saída). Em seguida, selecione o Tipo de Saída: se for acompanhado, um campo aparecerá para informar o nome do acompanhante. Opcionalmente, você pode anexar um documento do responsável pela retirada (RG, CNH, etc.).
4
Saídas
Visualizar e autorizar saídas do dia
  1. No menu lateral, clique em Saídas.
  2. Por padrão, o sistema mostra as saídas do dia atual. Use o campo de data para consultar outros dias.
  3. A seção Saídas Pendentes exibe um card por aluno com foto, horário, motivo e responsável.
  4. Quando o aluno estiver pronto para sair, clique em Autorizar Saída.
  5. A saída passa para a seção Concluídas.
  6. Para corrigir dados de uma saída ainda pendente, clique em Editar ao lado do botão de autorização.
Histórico de 30 dias O sistema mantém o registro das saídas por 30 dias. Saídas com mais de 30 dias são removidas automaticamente.
5
Histórico de Saídas
Consultar saídas já registradas
  1. Na tela de Saídas, use o campo de data para consultar as saídas de qualquer dia.
  2. Use o campo de busca por nome para filtrar as saídas daquele dia.
