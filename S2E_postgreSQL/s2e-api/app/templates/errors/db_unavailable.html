Banco de dados indisponível

O sistema não conseguiu se conectar ao banco de dados. Isso geralmente ocorre quando o projeto do Supabase está pausado.

Como resolver:
1. Acesse supabase.com/dashboard
2. Localize o projeto (estará com badge "Paused")
3. Clique em Resume e aguarde ~2 minutos
4. Volte e tente novamente

O plano gratuito do Supabase pausa projetos automaticamente após ~7 dias sem uso.
